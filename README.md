# AutoSign - 今日校园全自动打卡独立应用

## 🎯 核心功能与工作流

1. **每日定时精确唤醒**（默认每天 `06:31:00`，支持在界面自由修改）。
2. **Root 自动亮屏与解锁**：自动唤醒屏幕 $\rightarrow$ 上滑 $\rightarrow$ 自动键入数字 PIN 码 $\rightarrow$ 解锁手机。
3. **今日校园无障碍状态机**：
   - 步骤 1：自动点击底部导航【讯息】。
   - 步骤 2：自动点击【辅导员通知】。
   - 步骤 3：自动选取最下方/最新的今日签到通知。
   - 步骤 4：进入签到表单，点击【拍照/拍照打卡】。
   - 步骤 5：调起内置取景框，等待 1.5 秒对焦稳定后触发快门。
   - 步骤 6：自动点击【确定/勾选】确认使用照片。
   - 步骤 7：自动点击【确认提交】完成签到。
4. **留存存证与自动息屏**：
   - 签到成功后自动截屏保存至手机 `/sdcard/AutoSign/` 目录。
   - 延时 1.5 秒后自动关闭屏幕（息屏）。

---

## 📱 首次安装与使用配置指南

1. **启动应用并授权 Root（仅Root模式）**：
   - 打开 **今日校园自动签到** App。
   - 点击【授权 Root】，在弹出的 Magisk / KernelSU / APatch 授权窗口中选择 **永久允许**。
2. **开启无障碍服务**：
   - 点击【前往开启】跳转至系统无障碍设置，找到并开启 **“今日校园自动签到辅助服务”**。
3. **配置参数**：
   - 在输入框中填入你的 **锁屏数字 PIN 码**（用于息屏唤醒时自动解锁）。
   - 确认打卡时间（默认 `06:31`）。
   - 开启【启用每日定时自动唤醒与打卡】开关，点击【保存配置】。
4. **验证与调试**：
   - 先点击【测试解锁+启动】，观察手机是否能正常执行唤醒与进入今日校园。
   - 打开今日校园保持在首页，切换回 AutoSign 点击【立即执行签到】，观察日志窗口与各步骤跳转是否流畅。
4. **设置后台保活**：
   - 按照防断连保护设置应用的后台权限。
